Pertanyaan Sering Diajukan (FAQ)

Apakah ada biaya pemasangan awal (biaya pasang)?

Biaya pemasangan normal adalah Rp 150.000 (termasuk kabel fiber optic & setting router). Namun kami sering mengadakan promo Gratis Biaya Pasang untuk pembayaran langsung 2 bulan pertama!

Apakah benar internet ini benar-benar Unlimited tanpa FUP?

Ya, betul! Layanan RT/RW Net kami menggunakan skema Flat Rate Unlimited tanpa batasan FUP (Fair Usage Policy). Kecepatan internet Anda tidak akan diturunkan meskipun mendownload file besar.

Bagaimana jika terjadi cuaca buruk atau gangguan listrik?

Perangkat server pusat kami dilengkapi dengan UPS backup baterai otomatis. Selama jaringan kabel fisik tidak terputus, koneksi Anda tetap aktif saat mati listrik (selama router di rumah Anda tetap menyala).
